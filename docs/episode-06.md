# E06 — مقارنة الرندر (CSR / SSG / SSR)

## المشكلة
مفيش "قبل/بعد" هنا — دي مقارنة بين ثلاث استراتيجيات مختلفة، كل واحدة مناسبة لحالة مختلفة.

## للتصوير
1. افتح `/csr` — سجّل View Source (Ctrl/Cmd+U) ووضّح إن الصفحة فاضية غير الجافاسكريبت.
2. افتح `/static` — سجّل View Source، وضّح إن المحتوى موجود فورًا. حدّث الصفحة كذا مرة ووضّح إن الوقت ثابت.
3. افتح `/dynamic` — حدّث الصفحة ووضّح إن الوقت بيتغيّر كل مرة لأن السيرفر بيبنيها من جديد.

## للمستخدم
- CSR: `http://localhost:3000/ep/06-rendering/csr`
- SSG: `http://localhost:3000/ep/06-rendering/static`
- SSR: `http://localhost:3000/ep/06-rendering/dynamic`
- جرب View Source على التلاتة وقارن الفرق في المحتوى الأولي.
