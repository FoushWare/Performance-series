# E09 — Memoization

## المشكلة
حساب فرز تقيل (5000 عنصر) بيتكرر مع كل رندر، حتى لما نغيّر حاجة ملهاش علاقة بالبيانات نفسها.

## للتصوير
1. افتح `/before`، افتح الـ Console، اكتب في المربع — وضّح "sort" بيتنفذ مع كل حرف.
2. افتح `/after`، اكتب نفس الحاجة — وضّح إن "sort" بينفذ مرة واحدة بس.

## للمستخدم
- Before: `http://localhost:3000/ep/09-memo/before`
- After: `http://localhost:3000/ep/09-memo/after`
- الفرق: `useMemo` مع مصفوفة اعتماديات فاضية — الحساب بيتخزن ومايتكررش غير لو البيانات نفسها اتغيرت.
