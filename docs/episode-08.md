# E08 — Debounce

## المشكلة
مربع بحث بيبعت "طلب" (Console log هنا كمحاكاة) مع كل حرف بيتكتب، بدل ما يستنى المستخدم يخلص كتابة.

## للتصوير
1. افتح `/before` واكتب كلمة كاملة بسرعة عادية — وضّح العدّاد بيزيد مع كل حرف.
2. افتح `/after` واكتب نفس الكلمة بنفس السرعة — وضّح العدّاد بيزيد مرة واحدة بس بعد ما توقف.

## للمستخدم
- Before: `http://localhost:3000/ep/08-debounce/before`
- After: `http://localhost:3000/ep/08-debounce/after`
- الفرق: دالة `debounce` بسيطة بـ `setTimeout` + `clearTimeout`، من غير أي مكتبة خارجية.
