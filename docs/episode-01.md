# E01 — القياس (Web Vitals)

## المشكلة
مفيش "قبل/بعد" هنا — دي أداة القياس اللي هتستخدمها في كل حلقة تانية عشان تثبت إن الإصلاح فعلاً بيفرق.

## للتصوير
1. افتح `/ep/01-vitals` وسجّل الشاشة فاضية الأول.
2. تفاعل مع الصفحة (اسكرول، دوس حاجة) — وضّح إن الأرقام بتظهر لايف تحت وفي الـ Console.
3. اربط بصريًا: "الأرقام دي هي المرجع اللي هنرجعله في كل حلقة جاية."
4. اختم بـ: "خد لقطة للنتيجة دلوقتي — هنقارنها آخر السيزون."

## للمستخدم
- شغّل `npm run dev` وافتح `/ep/01-vitals`.
- افتح Console شوف قيم LCP/INP/CLS بتتسجل بمجرد ما تتفاعل مع الصفحة.
- ارجع للصفحة دي بعد كل تحسين في حلقات E03 وما بعدها، وقارن الأرقام قبل/بعد فعليًا على نفس الجهاز.
